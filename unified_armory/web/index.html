Unified Armory installer

Installs the mod into Halo: The Master Chief Collection. You choose your armor in the game itself.

1 Campaigns

Each checked campaign gets every armor piece from every game you have Mod Tools for. Mod Tools are free in Steam: Library › Tools.

    Settings

    Only needed if a folder wasn't found automatically.

    2 Install

    Builds the armor pack and installs the mod. The first time takes a few hours: every campaign level is rebuilt. You only do this once.

    
    
    
  
    

  
    
    
    3 Play
    
    
      
      
    1. Start Halo: MCC and choose Play with mods (EAC off).
      2. 
      
    2. In the main menu, press F8 and pick any helmet, chest, shoulders and more, from any game.
      3. 
      
    3. Start any campaign mission. Your armor is on. Press F8 in a mission to change it live.
      4. 
    
    
    
    The mod doesn't change MCC's own files. Uninstall (or deleting version.dll from MCC's
      mcc\binaries\win64 folder) puts everything back.
